# 16 — Feature: Share Loan Summary & Export Improvements

**Priority:** Medium  
**Status:** ❌ Not started  
**Goal:** Let users share their loan summary with a partner, broker, or accountant — native share sheet, zero new dependencies.

---

## Part A — Share Loan Summary (text)

### Why

Sharing = organic discovery. Users discuss loans with partners and brokers. Currently the only way to share is a PDF export, which is heavy and premium-gated. A lightweight text share is free to implement and can live outside the paywall.

### Implementation

Add `ShareSummaryCommand` to `LoanViewModel`:

```csharp
ShareSummaryCommand = new Command(async () =>
{
    var summary = BuildShareText();
    await Share.RequestAsync(new ShareTextRequest
    {
        Title = "My Loan Summary",
        Text  = summary
    });
});

private string BuildShareText()
{
    return $"""
        Loan Summary
        ─────────────────────
        Property Value:     {PropertyAmount.ToCustomCurrencyRounded()}
        Loan Amount:        {(HomeLoanInfo?.LoanAmountDirectInput ?? 0).ToCustomCurrencyRounded()}
        Deposit:            {(HomeLoanInfo?.DepositAmountDirectInput ?? 0).ToCustomCurrencyRounded()} ({DepositPercentage:0.#}%)
        Interest Rate:      {InterestRate}%
        Loan Term:          {LoanTermInYears} years
        ─────────────────────
        {RepaymentFrequencySelected.Trim()} Repayment: {HomeLoanInfo?.PaymentSummary?.Payment?.TermPayment.ToCustomCurrencyRounded()}
        Monthly Repayment:  {HomeLoanInfo?.PaymentSummary?.Payment?.TermPaymentMonthly.ToCustomCurrencyRounded()}
        Total Interest:     {HomeLoanInfo?.PaymentSummary?.Payment?.TotalInterestPayment.ToCustomCurrencyRounded()}
        Total Repayment:    {HomeLoanInfo?.PaymentSummary?.Payment?.TotalPaymentRounded.ToCustomCurrencyRounded()}
        ─────────────────────
        Generated by Loan Affordability Calculator
        """;
}
```

Add a share button to the Asset tab toolbar or as a secondary action near the repayment summary — `ImageButton` with a system share icon.

## Part B — PDF export improvements

The existing PDF export (Insights tab) is premium-gated and works. Consider these improvements:

1. **Show export button on Asset tab too** — not just Insights. Many users never reach Insights.
2. **Export filename**: rename from a generic name to `LoanSummary_$PropertyAmount_$Date.pdf` so it's identifiable in Files app.
3. **After export**: show a `Share.RequestAsync` on the generated PDF path so the user can AirDrop or email without going to Files first.
